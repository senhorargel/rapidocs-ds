# Logo / Marca Rapidocs

Esta pasta guarda a **logo do Rapidocs em SVG** (e outros arquivos de marca).

## Como subir a logo
Arraste o arquivo `.svg` aqui dentro. Sugestão de nome:

```
assets/logo/rapidocs-logo.svg
```

O nome é livre — se tiver mais de uma versão, pode subir várias, por exemplo:

- `rapidocs-logo.svg` — logo principal
- `rapidocs-logo-horizontal.svg` — versão deitada
- `rapidocs-logo-icone.svg` — só o símbolo/ícone
- `rapidocs-logo-clara.svg` / `rapidocs-logo-escura.svg` — para fundo escuro/claro

## Por que SVG?
SVG é um formato que **não perde qualidade** por mais que aumente de tamanho —
ideal para web e para mostrar na vitrine (Storybook).

## Depois
Quando a logo estiver aqui, dá para exibi-la na vitrine numa página de "Marca".
É só pedir. 🙂
